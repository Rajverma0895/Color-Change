# 🎨 Color Change & Box Fun

An interactive web application that lets you dynamically change background colors and create/manage colorful animated boxes.

## ✨ Features

### Background Control
- **Change Background** - Apply a random color to the page background
- **Reset Background** - Restore the default gradient background

### Box Controls
- **Add Box** - Create a new animated box with a random color (max 50 boxes)
- **Remove Box** - Remove the last added box with a smooth exit animation
- **Remove All** - Clear all boxes at once
- **Toggle Colors** - Switch all boxes between random colors and light blue
- **Click Individual Boxes** - Click any box to change its color randomly

## 🚀 Demo

Simply open `index.html` in your browser to start using the application.

## 🎯 How to Use

1. Clone or download this repository
2. Open `index.html` in any modern web browser
3. Use the control buttons to:
   - Change the background color
   - Add colorful boxes
   - Interact with individual boxes by clicking them
   - Toggle all box colors at once
